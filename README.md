SmartBudget Manager — README
Quick Reference & Getting Started Guide
1. What is SmartBudget Manager?
SmartBudget Manager is a simple Excel workbook created to help salaried workers, students, and beginners track their monthly budget. It lets you record income, add daily expenses, categorize purchases, and automatically view your balance and spending charts on a clean Dashboard.
2. System Requirements
• Application: Microsoft Excel 2016, 2019, 2021, Microsoft 365, or compatible spreadsheet software.
• Operating System: Windows, macOS, or Excel Web.
• File Format: .xlsx (OpenXML Spreadsheet).
3. Workbook Structure
• Dashboard: Shows summary cards (Total Income, Total Expenses, Balance, Status), category comparison table, budget control, and a pie chart.
• Transactions: Main table where you enter Date, Description, Type, Category, Amount, and Notes.
• Categories: Lists predefined categories (Food, Transport, Rent, Health, Education) and their monthly limits.
4. Quick Start (4 Steps to Get Started)
Step 1: Open the file SmartBudget_Manager.xlsx in Microsoft Excel.
Step 2: Check the Categories tab to review or adjust monthly budget limits.
Step 3: Go to Transactions, enter your salary in row 4, and start adding daily expenses in following rows.
Step 4: Click the Dashboard tab to monitor your balance, spending by category, and pie chart in real time.
5. Important Rules & Data-Entry Guidance
• Use drop-down lists for Type and Category to prevent formula calculation errors.
• Enter amount into either Income or Expense column (never both on the same row).
• Do not overwrite the Month column in Transactions or formula cells in Dashboard.
• Check the Budget Status card: if it turns red/salmon ('OVER BUDGET'), you have exceeded your spending limit.
